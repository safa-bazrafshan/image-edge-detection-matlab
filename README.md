# Image Edge Detection using MATLAB

This project demonstrates basic edge detection techniques using MATLAB. It includes applying popular edge detection algorithms such as Sobel, Prewitt, and Canny to grayscale images.

## Overview

Edge detection is an essential step in many computer vision and image processing tasks. In this project, we:

- Load and visualize a color image
- Convert the image to grayscale
- Apply different edge detection filters
- Compare and visualize the results

## Tools & Environment

- MATLAB R2023a
- Image Processing Toolbox

## Files Included

- edge_detection.m – main script for image processing
- images/ – output screenshots for grayscale and edge-detected images
- report.pdf – (optional) project summary and results
- README.md – project description
